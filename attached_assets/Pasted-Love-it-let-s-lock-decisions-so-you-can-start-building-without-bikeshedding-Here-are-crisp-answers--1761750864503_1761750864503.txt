# Minimal schema (Postgres)

```sql
-- communities
CREATE TABLE community (
  id             BIGSERIAL PRIMARY KEY,
  name           TEXT NOT NULL,
  description    TEXT,
  prompt_text    TEXT NOT NULL,
  prompt_hash    BYTEA NOT NULL,
  policy_id      TEXT NOT NULL,
  policy_json    JSONB NOT NULL,
  visibility     TEXT DEFAULT 'public', -- public|invite
  creator        BYTEA NOT NULL,        -- wallet addr
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- endorsements (append-only log)
CREATE TABLE endorsement (
  id             BIGSERIAL PRIMARY KEY,
  community_id   BIGINT NOT NULL REFERENCES community(id),
  endorser       BYTEA NOT NULL,
  endorsee       BYTEA NOT NULL,
  prompt_hash    BYTEA NOT NULL,
  epoch_hint     BIGINT,                -- optional
  signature      BYTEA NOT NULL,        -- EIP-712
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX ON endorsement(community_id, endorser);
CREATE INDEX ON endorsement(community_id, endorsee);

-- snapshots (finalized)
CREATE TABLE snapshot (
  community_id   BIGINT NOT NULL REFERENCES community(id),
  id             BIGINT NOT NULL,       -- monotonically increasing per community
  params_hash    BYTEA NOT NULL,
  log_root       BYTEA NOT NULL,        -- Merkle STH of endorsements included
  manifest_hash  BYTEA NOT NULL,
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (community_id, id)
);

-- scores (per snapshot)
CREATE TABLE score (
  community_id   BIGINT NOT NULL,
  snapshot_id    BIGINT NOT NULL,
  address        BYTEA NOT NULL,
  accepted       BOOLEAN NOT NULL,
  sts            INTEGER NOT NULL,      -- 0..100
  min_cut        INTEGER NOT NULL,
  seeds_used     BYTEA[] NOT NULL,      -- list of seed addresses
  per_seed_share JSONB NOT NULL,        -- {seed: share}
  vertex_disjoint_paths JSONB NOT NULL, -- witnesses
  cut_witness    JSONB NOT NULL,        -- minimal vertex cut
  PRIMARY KEY (community_id, snapshot_id, address)
);

-- params history (policy changes)
CREATE TABLE policy_history (
  community_id   BIGINT NOT NULL,
  policy_id      TEXT NOT NULL,
  policy_json    JSONB NOT NULL,
  effective_snapshot BIGINT NOT NULL,
  PRIMARY KEY (community_id, effective_snapshot)
);
```

# EIP-712 endorsement (community-aware)

```ts
// domain: { name: "TrustFlow", version: "1", chainId, verifyingContract }
types Endorsement = {
  community_id: bytes32,
  endorser: address,
  endorsee: address,
  prompt_hash: bytes32,   // keccak256(prompt_text)
  epoch: uint64,          // optional; for anchoring
  nonce: uint64
}
```

* Verify on ingest; **reject** if `prompt_hash` ≠ community.prompt_hash.
* Store in community’s transparency log; include in snapshot by log index range.

# Scoring job (per community)

1. **Freeze set** of endorsements for this snapshot (by log index).
2. Build node-split graph; capacities from policy (distance-decay; **lagged distances ON**).
3. Max-flow; compute **min-cut**, **vertex-disjoint≥2** (Suurballe on node-split), **per-seed share**.
4. Mark accepted; compute STS (optionally with ≤5% seed-PPR/EigenTrust).
5. Emit `scores.jsonl`, `cut_witnesses/`, `manifest.json` (signed).
6. Insert `snapshot` + `score` rows.

# MVP UI flow (prioritized)

1. **Create Community**

   * Name, description, **prompt text** (shows preview; displays “Public & permanent”).
   * Choose template (**Hiring/Lending/Marketplace/Custom**).
   * Submit → **you’re Seed #0**; get invite link.

2. **Invite & Vouch**

   * Members arrive on community page; see **prompt** atop the vouch button.
   * Vouch modal shows prompt + public/permanent note; sign EIP-712.

3. **Snapshot**

   * Auto finalize daily/hourly (or manual button in MVP).
   * Page shows **Accepted** badge and “**Why**”:
     “2 vertex-disjoint paths via A & D; seeds S1,S3 (≥0.30 each); min-cut=3.”
   * “How to improve” hints (diversify seed regions, reduce hub reliance, etc.)

4. **Directory (simple)**

   * List of communities with **health chips**: seed saturation, λ₂, coverage.

# Backward compatibility

* Migrate existing data to **Community 0** (name: “Global”).
* Set its `prompt_text` to your current global prompt; `prompt_hash` = keccak(prompt).
* Everything else “just works” with `community_id = 0`.

# Guardrails to keep from day one

* **Acceptance gates:** min-cut ≥2, **vertex-disjoint ≥2**, per-seed share ≥0.30.
* **Lagged distances** (capacities use previous snapshot’s distances).
* **Cut-witness proofs** (publish per accepted address).
* **Reciprocity cooldown** (24–48h) for risk flags/eligibility (if you add incentives).
