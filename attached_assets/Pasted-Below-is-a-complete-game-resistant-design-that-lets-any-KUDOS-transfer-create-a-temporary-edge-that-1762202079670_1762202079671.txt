4. Why This Is Still Ungameable

Why It Fails

Each KUDOS edge has 0.1× base → 10× less flow than social edges. Min-cut still caps total influence.

Distance decay + fast 30-day halflife → must keep sending every month. 1 % fee burns capital.
Wash-trade loops
Net flow ≈ 0 → no sustained boost. Fees eat 1 % per cycle.
Fake high-score user
KUDOS edges need seed proximity to matter. Distant transfers give near-zero flow.

9. Implementation (Solidity + Off-chain)
// KudosEdge.sol
struct Edge {
    uint8 edgeType;     // 0 = none, 1 = social, 2 = kudos
    uint256 weightedSum;
    uint256 lastUpdate;
}

// On transfer
function _afterTokenTransfer(address from, address to, uint256 amount) internal {
    Edge storage e = edges[from][to];
    uint256 weight = amount * 1e18;  // avoid float
    e.weightedSum = e.weightedSum * decayFactor + weight;
    e.lastUpdate = block.timestamp;
    if (e.edgeType == 0) e.edgeType = 2;  // kudos edge
}
Decay precomputed off-chain or via oracle.
