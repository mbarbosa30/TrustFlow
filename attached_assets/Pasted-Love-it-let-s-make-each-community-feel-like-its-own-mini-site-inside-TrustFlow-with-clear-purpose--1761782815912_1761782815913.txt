Love it—let’s make each community feel like its own mini-site inside TrustFlow, with clear purpose, live metrics, and safe conversations.

Community Page: What it includes

Header (hero)
	•	Logo + name + location
	•	One-line mission
	•	CTAs: Apply for Credit · Vouch · Support (or Sponsor)
	•	Optional cover image and custom theme colors

Key stats (top row, auto-refresh per epoch/day)
	•	Trust: Accepted users · Trust health index (min-cut & diversity)
	•	Credit: Active loans · On-time rate (90d) · PAR30 · Avg ticket
	•	Support: Sponsors active · Interest subsidized (last 30d) · First-loss cap remaining
	•	Activity: Vouches (7d) · Workshops/Events upcoming

Tabs
	1.	Overview – mission, who they serve, programs, quick KPIs, latest update
	2.	Credit – borrower view (eligibility, offers, active loan progress, repay, receipts)
	3.	Trust – how to vouch (prompt), your score, “why accepted”, tips to improve
	4.	Impact – charts (repayment funnel, subsidy impact, cohort performance), stories
	5.	Updates – posts + comments (announcements, workshop notes, Q&A)
	6.	People – seeds, mentors, operators (roles & public bios)
	7.	Transparency – signed parameters, hashes, receipts feed, policy history

⸻

Comments/Updates (safe & useful)
	•	Posts: admins/seeds share updates (workshops, fairs, calls for action)
	•	Comments: threaded, emoji reactions, file/image attach
	•	Badges on commenters: Borrower · Mentor · Seed · Sponsor (read-only labels)
	•	Safety: rate limits, first-comment hold, report/flag, spam filters; option “comments from accepted users only”
	•	Privacy: never expose private graph edges; posts are public by default

⸻

Admin Console (per community)
	•	Branding: logo, colors, cover, custom slug/domain
	•	Mission & copy: Markdown editor for Overview; bilingual fields if needed
	•	Trust policy: prompt text, gates (min-cut, vertex-disjoint, seed coverage), seed list
	•	Credit presets: ARS amounts (160k–800k), tenors (6/9/12m), APR (40%), late/default rules
	•	Support rails: toggle Interest Buy-Down, Repay-Assist, First-Loss, voucher programs
	•	Events: workshops/ferias calendar
	•	Moderation: approve/feature posts, manage comments, block users
	•	Transparency: publish epoch bundles, receipts, policy changes (with timelock)

APIs (MVP)

Public
	•	GET /communities/:slug → branding + overview copy + CTAs
	•	GET /communities/:slug/metrics → top-row KPIs + sparkline data
	•	GET /communities/:slug/updates / GET /posts/:id
	•	GET /communities/:slug/transparency?since=...

Authed (wallet)
	•	GET /communities/:slug/me → { eligible, score, minCut, trust tips }
	•	GET /communities/:slug/credit/overview → borrower panel
	•	POST /communities/:slug/vouch → EIP-712 vouch
	•	POST /communities/:slug/posts / POST /comments (role-gated)

Admin
	•	PUT /communities/:slug/settings (branding, mission, theme)
	•	PUT /communities/:slug/policy (trust & credit presets)
	•	POST /communities/:slug/announce (creates pinned update)

⸻

Engagement patterns that work
	•	Progress bars: “On-time streak 3/3” for borrowers; “Subsidy this month: ARS 1.2M” for sponsors
	•	Milestones: “100 accepted members”, “Default rate under 2% for 90 days”
	•	Events widget: next 3 workshops/ferias with quick apply
	•	Nudges: “Add a mentor note” (mentors), “Invite a sponsor” (seeds), “Diversify your vouches” (borrowers)
	•	Shareables: OpenGraph cards for posts/impact highlights

	•	Comments require accepted status or moderator approval
	•	Anti-abuse: rate limits, cooldowns, shadow-ban for spam
